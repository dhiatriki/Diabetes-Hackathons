Model V1 Report: Data Understanding & Cleaning
==============================================

Summary of Changes
------------------
1. **Data Cleaning**:
   - Identified and removed duplicate rows (~2,870 duplicates).
   - Checked for missing values (handled via dropna, though data was mostly clean).

2. **Class Imbalance Strategy** (Crucial Improvement):
   - Identified that Class 1 (Pre-diabetes) had 0.00 Recall in Model V0.
   - Realized differentiating "Pre-diabetes" from "No Diabetes" is extremely difficult with this feature set.
   - **Decision**: Merged Class 1 (Pre-diabetes) into Class 0 (No Diabetes) to focus the model on the primary task: **Predicting Diabetes (Class 2) vs Non-Diabetic**.
   - Result: Eliminated the "dead class" problem and simplified the model's objective.

3. **Feature Preprocessing**:
   - Separated Numerical features (BMI, MentalHealth, PhysicalHealth, Age, Education, Income) from Categorical/Binary features.
   - Applied **StandardScaler** to numerical features to improve Logistic Regression convergence and performance.

4. **Evaluation**:
   - **Accuracy**: Increased to ~73% (vs 71% baseline).
   - **Confusion Matrix**: Now a clean 2x2 matrix with valid performance for both classes.
   - **Precision/Recall**:
     - Non-Diabetes (0): High precision/recall.
     - Diabetes (1): Recall ~0.62, Precision ~0.68. The model can now actually detect diabetes cases reliably.

Conclusion for Presentation
---------------------------
"By removing noise (duplicates) and redefining the problem to align with the data's limitations (merging weak classes), we achieved a solid 2-3% accuracy gain and, more importantly, a reliable model that actually detects the disease."
